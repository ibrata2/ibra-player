iBRA PLAYER
===========
برمجة و تطوير ابراهيم الخزرجي — Telegram: https://t.me/ibraprogram

System requirements
- Windows 10 or Windows 11, 64-bit
- A graphics driver with OpenGL 3.0+ (every current Intel, AMD and NVIDIA driver)
- About 300 MB of disk space

Portable use
- Keep the file "portable.ini" next to "iBRA PLAYER.exe": settings, history
  and themes are then stored in the "data" folder beside it instead of
  %APPDATA%\iBRA PLAYER.

Command line
  "iBRA PLAYER.exe" file1.mkv folder\ list.m3u8     open and play
  "iBRA PLAYER.exe" --enqueue file.mp4               add to the running player
  "iBRA PLAYER.exe" --register-context-menu          add the Explorer menu (current user)
  "iBRA PLAYER.exe" --unregister-all                 remove all Explorer integration

Diagnostic log: %APPDATA%\iBRA PLAYER\logs\ibra-player.log (file paths hidden by default)
